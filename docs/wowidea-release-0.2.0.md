# Wowidea 0.2.0 发布验证

日期：2026-09-08。仓库仅包含 CLI / Skill / 补充契约，没有网站后端源码。本版本不宣称已部署服务器功能。

## 已实现

- wowidea 主 Skill、easyai 兼容入口和三个 CLI 别名；中文首次安装与自然语言示例。
- 原计划 12 个模型及实测新增 Seedance 2.0-mini 共 13 个路由；7 份按系列加载的自包含指南。实时目录优先，2.0/2.5 隔离；不可用不替换。
- Windows/macOS 源码安装器采用 npm pack 后安装实体 tgz；同时同步 Skill，保留用户修改及账号配置。
- API Key 本机隐藏输入 / 系统凭据库；默认模型、版本与任务索引持久化，不存 Key。
- 提交前持久化幂等键与请求 hash。任务查询只接受明确匹配，不把首条记录当结果；重启恢复不 POST。
- 图片和视频 watch 有截止时间；下载只选择结果字段。Seedance 分镜图字节、参考 hash、提示词与设置绑定审批；manifest 必需，同一本机批准通过原子文件声明防并发重投。
- 服务端报价必须有有效费用和期限，绑定凭据作用域、执行路径与序列化请求；本地未知报价不可扣费提交。
- Seedance 保留私有 MinIO 上传、watermark:false、manifest payload 导出、ledger、接触表、尾帧与多个时间点右下角采样。QC 需实际目视确认，不能自动宣布通过。

## 验证证据

- npm run check：类型检查、构建、10 个测试文件 / 33 项测试通过。
- 测试包含默认/指定/不可用模型、版本隔离、指南文件完整性、未批准 Seedance 直提阻止、图片接口绕过阻止、序列化 hash、未知报价拒绝。
- 模拟任务覆盖无结果、不匹配、歧义、查询断网、重启恢复、并发重复批准；两个真实 CLI 进程共一次 POST。
- Skill 更新测试验证自定义文件不覆盖、待合并版本保留、账号配置字节不改变。两个 Skill 的官方 quick_validate 验证通过。
- Windows 已从 tgz 安装到实际 npm 全局目录，在源码目录外验证三个命令均为 0.2.0，包目录不是符号链接。本机 wowidea Skill 已安装，已有 easyai 主入口可识别升级；未识别的本地参考修改保留。
- Windows 完整安装脚本也已从本地 Git 仓库克隆到独立临时目录，执行 npm ci、构建、打包、全局安装及 Skill 同步；脚本清理临时源码后，再次在源码目录外验证三个命令和既有 API Key 正常。下载 GitHub 仓库这一网络步骤由 Git 提供，未把本地克隆实测伪称远程下载测试。
- macOS 安装脚本通过 Git Bash 语法检查；没有 macOS 真机，不把此结果当作 macOS 凭据库和安装实测。
- 线上只读取模型、账号认证状态、余额和已有任务；成功下载已有图片任务 6a9e6a2f7e18d7bc6516eb00。下载 SHA-256：a0e016147a694cea1a645312ca7f9b39dcb9ec3802982676a105f3cbd935a49b。
- 本轮没有新建任何付费图片或视频任务，没有修改线上画布。

## 仍依赖后端或后续实测

- 线上预检报价和各模型生成端到端本轮未做付费验收。服务器必须提供 quoteId、normalizedRequest、payloadHash、estimatedCost 和 expiresAt；缺失时阻止生成。
- 引用媒体的编码、像素、参考时长/总时长以及复杂编辑/续写组合仍须由服务器预检验证。未公开支持的模式在本地阻止，不擅自转换。
- 跨设备、配置目录丢失或恶意客户端的全局防重必须由后端原子幂等表实现。服务端查询不返回幂等键时 CLI 保持 uncertain；补充契约已加入 OpenAPI。
- 含 Seedance 的画布执行尚未接入 manifest 批准桥接，暂时阻止，通过 video generate --manifest 执行。
- MinIO 连通、有效付费报价、真实视频/尾帧与 ffmpeg QC 本轮未新建任务验证。不能把测试通过视作这些线上环节已验收。
- 自然语言需求补全由 Codex 按 Skill 指南执行；未进行独立模型行为评测，不保证每个提示词获得相同构图效果。

完整计划中的服务端费用预检、账号 beta 与各模式付费端到端验收，需要在实际网站源码与测试账号环境继续落实。
