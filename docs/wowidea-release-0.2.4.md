# 0.2.4：分镜审美、来源绑定与防重复

本版本修复“分镜没有保持用户选定原图，却被代理误判为合格”。实际案例中，候选分镜改变了房屋、游乐设施、机位和构图，并生成了提示词明确禁止的时间文字；同一分镜 payload 还被换用第二个幂等键再次提交。

- 新增分镜视觉 QC：来源构图、地标、透视、色调，以及视觉层级、时间连续性、物理可信度和独特性均需实际看图评分；硬性错误未解决不能批准。
- 参考模式下，每个 storyboard shot 必须通过 `sourceRoles` 绑定 manifest 中的真实素材角色。分镜 contact sheet 只用于审核，不会被误当作最终视频参考。
- 参考驱动的第一格直接使用用户选定原图；后续关键帧单独生成，多格板在本地用真实帧组合，避免图片模型在一次 2×2 生成中重构整个场景。
- 所有 Seedance 都要求用户明确批准已通过 QC 的分镜。200 积分阈值只控制额外费用确认：≤200 不再问费用，>200 再确认完整计费设置。
- CLI 阻止相同 payload 换新幂等键重复提交，并指出原键和 taskId。只有用户明确要求另一版时才允许 `--allow-reroll`。
- 批准哈希绑定本地参考素材字节，但不绑定会过期的签名 URL 查询信息；上传私有 MinIO 不会无故改变已批准的创意身份。

测试覆盖低审美分数拒绝、硬性错误拒绝、缺失来源角色拒绝、参考素材字节绑定、临时签名元数据稳定性、相同 payload 防重复，以及 200/201 积分在已完成创意批准后的费用边界。本次没有生成新的图片或视频任务。
