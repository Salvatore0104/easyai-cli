# 0.3.2：按设计用途分流，舞台作为专门分支

审查发现：入口描述限定VJ／舞台；通用词“主视觉、空间、循环、变形”会误触发舞台配方；通用方向、图片骨架和QC偏重演员留空、远距离与冲击力；README和CLI描述也重复了该定位。

本次修正入口与产品描述，新增design-tasks指南，按海报、品牌、产品、电商、插画、空间、界面概念、视频、舞台与局部编辑选择方法。未知类型按实际用途判断，不强塞入已有分类。通用方向和QC改为任务导向，舞台条件独立标注；图片提示骨架不再默认舞台构图。保留VJ方法及两份舞台配方，但仅在相关任务使用。

单张图片与局部修图不要求节目建档或分镜。持续项目兼容现有project schema，非舞台项目stage留空；未更改档案结构。现有Seedance分镜审批、费用设置、防重复与任务恢复继续适用，无新增付费测试。
