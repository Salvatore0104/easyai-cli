# Codex 首次安装
复制 README 开头的提示词给 Codex，安装器会同时安装 CLI、wowidea 与兼容 easyai Skill。macOS 与 Windows 命令见 [README](../README.md)。
凭据通过 `wowidea auth use-key --prompt` 在本机隐藏输入，不把 Key 发到聊天；不执行浏览器登录。
验证 --help、auth status、models route --kind image、balance 和 tasks list。不为了验证安装创建付费任务。
安装后下一轮使用 `$wowidea` 或“使用 wowidea”。任务恢复先查索引与 ID，不重新生成。
