# 0.2.2：只监控 Seedance 超过 200 积分的生成

- 仅 Seedance 视频使用费用确认门槛：预计 ≤200 积分直接执行，>200 积分才确认。200 不确认，仍要求有效服务器报价来判断门槛。
- 图片、MiniMax、Google Omni、Wan 等非 Seedance 任务不再自动预检费用，不要求 --quote / --yes / --max-cost，直接生成。没有 Seedance 的普通画布同样取消费用门槛。用户主动提供预算参数时仍校验其明确限制。
- 所有模型仍保留参数校验、幂等防重、异步轮询、下载和实际积分报告。费用不监控不等于不等待任务完成。
- Seedance 分镜、manifest、私有素材、watermark:false、单任务保护仍保留；只在报价超过 200 时等待确认。

验证覆盖 200/200.001/201 的边界，以及图片和 MiniMax 不请求预检、无需确认直接提交的 CLI 路径；实际积分 JSONL 输出继续验证。未新增付费任务。线上任务未返回实扣积分的限制沿用 0.2.1，仍会明确显示未返回。
