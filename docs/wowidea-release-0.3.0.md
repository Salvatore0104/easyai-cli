# 0.3.0：面向 VJ 与舞台设计的专业视觉 Agent

此前CLI已有可靠的API执行层，但节目创作依赖零散参考，模型指南缺少官方H3结构及Seedance版本差异。现在由Codex Skill按节目意图组织方向、素材、提示词与评审，CLI提供可移交档案和离线资源接口。

## 本次行为

- 新增project init/show/validate/record，节目档案与单次创作分开；初始化／记录拒绝覆盖，试验不会提升为长期偏好。
- 新增guides list/show；models route保持旧字段并追加guideInfo和能力边界说明。
- 六类VJ创作方法与节目意图评审，支持超现实、创新和冲击力。保真仅针对约定维度，风格参考不自动锁定首帧构图。
- Seedance 2.0／2.5、H3、Nano Banana、GPT Image 2专用指南及来源管理。所有Seedance在批准前展示完整设置；200积分只控制额外费用确认。
- 锁定四个GitHub来源版本，按MIT捆绑四类小型风格元数据，其余使用原创总结和出处。资源摘要和内部链接纳入check与打包前检查。

## 验证

类型检查、构建、资源完整性与72个测试通过，覆盖原审批／费用／恢复行为、新档案隔离、引用顺序、H3未支持模式拒绝、资源安装和自定义修改保留。npm打包包含完整Skill、来源与示例。另进行实际tgz异目录离线命令及安装更新冒烟验证，记录在开发交付中。

[离线创作验收](offline-creative-acceptance.md)覆盖抽象VJ、超现实主视觉、H3动作参考与节目续作。示例档案没有虚构用户批准、任务ID或QC成功结果。

## 限制

已完成GPT Image 2图片和H3纯文本视频付费冒烟；图片参考测试详见[实测记录](live-smoke-20260908.md)。实测不等于现场LED或完整多模态组合验收。官方sd25-pe分发端点本次返回404，未取得原Skill；2.5适配来自可读取的官方指南。MiniMax官方提示方法已核验，但未捆绑无明确Skill级许可的完整原包。当前平台未暴露的高级模式只提供策划和缺口提示；不改网站后端，不自动后期或额外生成。

发布包版本0.3.0，保留wowidea/easyai/easyai-canvas。安装器继续保留用户凭据与自定义Skill，节目目录独立存储。
