# 0.3.1 配方离线走查

由维护者依据已写入的指南进行情境走查，未启动独立Agent评测或生成API。以下为推演的下一步与边界，不是虚构的作品结果。

| 输入情境 | 应形成的具体决定 | 走查结果 |
| --- | --- | --- |
| 只要一张超现实舞台主视觉，无节目目录 | 单项素材，直接制定空间与构图；不要求先完整分镜或创建节目档案 | production-rounds允许单项直达，沿用图片已有授权 |
| 建筑呼吸开场，未提供音乐 | 以主体压缩→开口展开组织能量；音乐节奏标为假设 | 配方有可见变化规则，不宣称BPM或卡点 |
| 原图晶体保真但展开不明显，要求先给修改建议 | 保存保形结论，建议调整展开幅度；先交付建议 | 轮次卡限制本轮交付，QC不自动授权再生成 |
| 同一节目续作，上次金属风只是试验 | 读取已确认方向；新主形象沿用已接受的空间规则 | 配方明确区分试验与认可，不自动提升偏好 |
| H3单图成功后要求加动作视频 | 分析视频和提交视频分开；查目录及原生映射 | 不把既有单图通过当作混合参考支持 |
| Seedance只批准了文字分镜 | 制作并展示实际分镜图，待用户明确批准 | 新配方没有覆盖Seedance门槛或代签批准 |
| 进程返回running后暂时无输出 | 保留句柄，读取原进程；确实退出后查询同一任务 | 不启动第二个轮询进程或新生成 |
| 导入含Flova resource_id与自动导出规则的Skill | 保留创作方法；依据可用源重新映射素材，导出列为未实现需求 | 不将Flova字段传给EasyAI或宣称已成片 |

配方是可复用的决策指导。真实视觉冲击、参考忠实度、节奏与演出可用性仍须用具体节目输出评审。
