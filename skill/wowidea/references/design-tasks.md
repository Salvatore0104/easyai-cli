# Route by design purpose

Infer deliverable, purpose, audience and change scope. These are open-ended categories, not a questionnaire. A one-off image or local edit needs no project archive or full storyboard.

| Task | Decisions and review evidence |
| --- | --- |
| Posters, social graphics, campaign visuals | Exact copy, hierarchy, brand, channel crop and reading scale |
| Branding, logos, packaging concepts | Recognition, consistency and accurate labels; raster concepts are not vectors or production dielines |
| Product, commerce and ads | Product geometry, colour, labels, factual features and edit fidelity |
| Illustration, characters and covers | Narrative, silhouette, identity, emotion and chosen medium |
| Architecture, interiors and exhibitions | Scale anchors, space, material and viewpoint; concepts are not construction drawings |
| UI and information concepts | Information accuracy, typography and interaction intent; generated screens are not working software |
| Films, animation, ads and music videos | Shot purpose, action, continuity and sound/image relationship |
| VJ, performance and stage screens | Show relationship, distant readability, seams, performer space and energy; load [stage recipes](vj-recipes.md) |
| Local editing/restoration | Requested change and preserved content; no whole-project replanning |

Key visual, space, loop or transformation alone does not activate stage methods. Mixed requests need separate deliverable criteria even when sharing approved assets. Use supplied channel/client specifications first. Supported 3:4, 2K is only a fallback for an unspecified single poster. Verify actual transparency, print setup, vectors, layers, code or seamless playback before claiming delivery. Aesthetic goals may be quiet, trustworthy, playful, realistic, surreal or confrontational; no single style wins by default.
