# 设计任务分流

先从用户请求和素材判断交付物、使用场景、受众及修改范围。信息充分时直接选用对应方法，不让用户先选Skill。任务可以组合，以下不是封闭分类；其他设计按其用途建立标准，不能默认归入舞台。

| 任务 | 优先决策与评审 | 需要时才展开 |
| --- | --- | --- |
| 海报、社交图、活动主视觉 | 准确文案、阅读层级、主体与信息关系、发布渠道裁切 | 系列版式；无视频需求不做分镜 |
| 品牌、标识、包装概念 | 识别性、品牌调性、应用一致性；包装文字和结构依据 | 应用场景；位图概念不冒充矢量标识、刀版或可印刷源文件 |
| 产品、电商、广告图 | 产品形状、颜色、标签、卖点与使用场景真实对应 | 多角度／系列图；不编造产品功能或把风格参考当商品身份 |
| 插画、角色、封面 | 叙事、造型语言、人物身份、情绪、构图与媒介质感 | 系列设定；不自动添加舞台留空、暗背景或巨大主体 |
| 空间、建筑、展陈概念 | 尺度锚点、空间关系、材料、视角与用途 | 多视角；概念图不等于施工图或舞台屏幕方案 |
| 界面或信息设计概念 | 信息准确性、层级、字号、交互意图和可读性 | 屏幕状态；生成效果图不等于可运行界面或可编辑图表 |
| 广告片、叙事短片、动画、MV | 镜头职责、主体连续性、动作、声画关系与时长 | 多镜头才展开时间结构；非演出视频不默认走VJ配方 |
| VJ、舞台视觉、演出屏幕 | 节目关系、远距离可读性、能量变化、屏缝与表演区 | 加载vj-recipes及创作方向中的舞台段落 |
| 局部编辑、修复、换背景 | 只改变指定区域／属性，核对用户要求保留的内容 | 不重新策划整张图；模型不支持的编辑方式明确说明 |

## 规格和素材

渠道／客户给定尺寸优先。没给尺寸时按用途提出合理默认并说明；3:4、2K只是支持该规格的单张海报回退，不推广到横幅、产品图或视频。印刷像素与出血、透明背景、矢量、可编辑分层、UI代码等，只有工具实际支持并验证后才宣称交付。

创作可复用模型指南、素材映射与评审方法，无需套用舞台配方。混合任务拆成相应交付物：例如演唱会海报看文案和版式，LED背景看屏幕与运动，二者可共享已确认品牌元素但不共享全部评审标准。

## 避免误路由

“咖啡品牌主视觉”先走品牌／海报；“超现实建筑空间”先走空间概念；“产品旋转循环”先走产品视频；“角色变形动画”先走叙事／动画。只有用户明确描述演出用途或指定舞台方法，才加载舞台专用资源。当前任务用途不清且会显著改变结果时，问一个关键问题，同时推进不依赖答案的素材分析。
