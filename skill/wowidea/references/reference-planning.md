# Reference roles and order

Inspect the source, then state what it controls, where it applies, what stays and what changes. Do not silently turn it into a strict first frame or include a review storyboard in the paid request.

Creative records use ordered references with type (image/video/audio), unique role, stable source, scope, preserve and change arrays. project record numbers each media type independently as image1/video1/audio1. Prompt labels follow the selected model's grammar.

Generate image_urls, video_urls and audio_urls from the same approved list without sorting filenames. H3 Subject labels name content, not file positions; Picture/Video/Audio labels resolve to matching assets. One entity can draw identity and movement from different sources. Audio from a video needs its own approved role. Motion reference does not automatically transfer actor, scenery or soundtrack.

Seedance references bind by role to storyboard.sourceRoles. Put retention intent in the prompt and record. Each expected array must contain exactly the approved count. Review images, original sources and generation inputs are separate roles.

Check live mode, native mapping, counts, media durations and audio combinations. An official creative mode or catalogue label alone does not prove an unimplemented adapter. If unsupported, deliver the prompt and gap; do not rename the mode, drop assets or switch provider. Seedance reference/creative changes invalidate approval.
