# GPT Image 2.5 prompt routing

For GPT Image 2.5, Flare, and Sunburst prompt writing or polishing, use the bundled [GPT Image 2.5 Prompt Polisher](../../gpt-image-25-prompt/SKILL.md). Then apply the common [GPT Image guide](gpt-image.md) for task structure, reference order, and visual review.

The prompt Skill changes prompt wording only. Keep API settings outside the prompt and validate the final request through [image parameters](image-parameters.md) and the live capability. Do not transfer 2.5 quality, output-format, background, or platform behavior to GPT Image 2.
