# Reusable creative recipes

Use to reuse a method or adapt an external Skill. Recipes are Markdown read by Codex, not Flova API objects. Keep one-off project values, IDs and approvals in project records.

Borrow Flova's responsibility boundaries:

| Source module | Local responsibility |
| --- | --- |
| planner | Deliverable, dependencies, user review points |
| multimodal_analyze_tool | Observed source facts and uncertainty |
| storyboard_designer | Direction, shot purpose and temporal structure |
| media_generator | Model capability, reference authority, execution |
| write_the_prompt | Model syntax, action and retention instructions |
| video_assembler | Real delivery preparation; unsupported assembly stays a gap |

Analysis does not authorize uploading every analysed source. Flova IDs, tags, tools and parameter ranges do not transfer to EasyAI. Keep only rules that change a decision: condition, choice, reason. Omit empty modules and generic quality advice.

Reusable outline: applicable task; inputs and assumptions; visible mechanism; source observations/roles; composition/shot decisions; needed model capability; prompt structure; observable QC; actual deliverable and remaining work.

Product-background recipe: inspect silhouette, label and contact surface; change background and necessary shadow while retaining product/crop. Use verified image editing with a concise prompt. Compare labels and edges; do not invent features or generate a video.

World-consistency recipe: for an explicitly accepted series direction, extract spatial, palette and material rules rather than copying every object. Change the requested subject while retaining those rules. Verify shared visible anchors and the new design's own purpose. Trials are not persistent preferences.

Stage expansion methods live in [VJ recipes](vj-recipes.md), not the default. Preserve attribution/licence for imported content, resolve conflicts and retain relevant methods only. Do not migrate installation scripts, credentials, paid entry points or service fields. Bundle reviewed updates; no runtime upstream sync.
