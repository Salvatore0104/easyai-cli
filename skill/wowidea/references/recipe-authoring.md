# 编写与复用创作配方

用于用户要求“以后都这样做”、引入外部Skill或固化一类设计方法。配方是Codex读取的Markdown，不是新增API或可提交的Flova Skill JSON。用户只想做一次作品时，把具体数值和素材留在项目记录。

## 将外部规则放到正确位置

借鉴Flova Skill Builder的职责拆分，只保留能改变本项目决策的规则，不机械填满模块：

| 外部模块 | Wowidea落点 | 应保留的内容 |
| --- | --- | --- |
| planner | 本轮计划／项目资料 | 目标、必要依赖、用户指定的检查点 |
| multimodal_analyze_tool | 素材分析 | 实际看见的造型、运动、材质、节奏证据；未知项 |
| storyboard_designer | 美术方向／分镜 | 主形象、景别、运动顺序、能量变化 |
| media_generator | 模型路由／素材映射 | 选择理由、保留与变化意图、真实能力校验 |
| write_the_prompt | 模型指南／提示词 | 模型专用结构、编号、可观察动作描述 |
| video_assembler | 交付准备 | 拼接、节奏、屏幕适配需求；未实现的不承诺 |

“读懂一段动作参考”和“提交该视频作运动参考”是两项决定。先分析出动作，再核对平台模式、素材权限与用户使用意图；不擅自把分析素材全部上传。素材名、Flova resource_id和asset_id都不能当作EasyAI任务或引用ID。

## 可直接复制的配方骨架

```markdown
# 配方名称：一种可复用的视觉方法
适用：哪类设计意图或素材条件需要它。
输入：最少需要什么；缺失时可以怎样规划，哪些生成需等待。
视觉机制：观众将看见什么变化，记忆点为何成立。
素材分析：应观察哪些证据；哪些结论不能由文件名或标签推出。
分镜规则：构图、空间、动作因果和节奏如何组织。
生成策略：按什么能力选择模型和引用角色；缺口如何报告。
提示词方法：用什么结构写清变化，转交哪份模型指南。
评审证据：哪些具体画面说明目标实现，哪些说明需要修订。
交付边界：本轮素材与最终演出交付之间还有什么工作。
```

每条规则优先写“条件 → 决定 → 原因”。例如“侧屏狭长时，将主要变化沿纵向组织，避免横向穿越被屏缝切断”，而不是“保证高级和震撼”。若用户要的正是碎裂式跨屏构图，保留该设计意图并说明实际拼接需求。

以下两份是舞台／节目分支的原创配方，仅在任务适用时复制。其他设计使用上方通用骨架，按[任务分流](design-tasks.md)建立自己的规则，不自动选择这两份。

## 配方：建筑呼吸与节奏爆发

适用：需要积蓄、释放对比的VJ段落；不用于要求全程均匀背景的段落。
输入：段落意图；已有主视觉可选。未提供音乐时只设计能量变化，不编造BPM或逐拍同步。
视觉机制：一个可远观辨认的巨型结构先压缩负空间，再通过大尺度展开释放压力。
素材分析：若有图，记录外轮廓、中央开口、材质边缘与舞台留空；若有音频，实际听取或分析段落依据，再描述累积与释放位置。
分镜规则：先建立完整轮廓，再让局部变化沿明确方向传播；高潮改变开口或主体尺度。载体可以是岩层、织物、晶体或抽象几何，不必都发光。
生成策略：只有文字可用时选目录支持的文本模式；已有主视觉并希望保形时核对图片参考。需要动作视频输入时独立核验视频参考映射，不能从单图测试推定支持。
提示词方法：写清起态、传播方向、从属延迟、终态及保留锚点；采用选定模型指南的格式。H3 Ref2VA用六段和同序Picture标签，Seedance先完成分镜图审核。
评审证据：比较早、中、晚采样的中央开口、主体尺度和局部朝向；静态保真但变化不明显时，分别报告两个结论。
交付边界：输出镜头素材及能量变化说明；卡点、多屏分割与无缝接缝需实际后期检查。

## 配方：同一世界中的超现实变体

适用：节目续作希望换主形象但延续已认可世界观；不自动把上次试验视作认可。
输入：用户确认的方向、可访问的已接受素材，以及本次希望改变的对象。未能查看旧图时先读取记录，说明尚未核验像素细节。
视觉机制：以共同空间规律连接不同主体，让观众感到同属一个节目而非重复同一构图。
素材分析：区分稳定风格锚点（如失重空间、材质反差、光色关系）与可变对象；不把参考里的每个物体都定义成必须保留的身份。
分镜规则：保留世界规则，改变本轮主形象及运动逻辑；有意超现实变化依据设定评审，不套用写实物理作为统一标准。
生成策略：普通风格／场景参考和严格首尾帧分别选择；旧图只是风格源时不额外添加首帧锁定。请求前明确各源保留哪些属性、允许改变什么。
提示词方法：把新主体放在主句，将保留风格写成空间、材质、光线关系；素材标签只出现在实际起作用的范围。调用[图片指南](gpt-image.md)或实际选定模型的指南。
评审证据：列出续作与旧图共享的两项可见规则，以及本轮新增的记忆点；不能只用“风格一致”作为结论。
交付边界：记录为本轮版本。只有用户明确认可新方向，才更新长期节目偏好。

## 引入与维护

先对比现有配方，合并重复或矛盾规则。用户明确提供可复用内容时保存来源和适配说明；可再分发的原文保留作者及许可。未核实授权时只保留方法的原创表达与来源记录，不捆绑全文或媒体。

外部Hub安装指令、凭据、付费入口、专用工具和服务器管理字段不迁移。Flova在线Skill审批／发布字段只适用于Flova，不给Wowidea增加额外的通用审批步骤；用户现有授权及Seedance门槛继续生效。

只将跨项目可复用的规则随包发布。节目名称、屏幕尺寸、实际素材、任务ID和批准记录放回节目档案。新增公开配方须从入口或指南链接可达，更新来源摘要及resources锁；运行时不自动同步外部Skill。
