# MiniMax H3 / H3-Max
项目自有平台适配，不是 MiniMax 官方 H3 Skill；未复制来源不明的本机 h3-prompt-writing。
先确认模式：文本、图像、首尾帧、视频/音频参考；按模型目录支持的模式选择。
提示词包含主体、按秒推进的动作、空间关系、一个主镜头运动、光线、环境音、对白与结尾状态。图生视频优先写变化与保持项，不重复描述整张图。
对白明确角色、语言、台词及发生时点；参考音频注明节奏/音色/环境用途，不能自行添加参考。
H3 与 H3-Max 的音频、时长、分辨率分别校验；例如目录要求声音开启时先告知用户，不静默更改已批准设置。
不向 API 强塞 integrated_multimodal_description 等上游字段，除非平台当前请求契约明确支持。
