# Seedance 2.0 / 2.0-fast
提示词创作部分改编自 MIT 社区 seedance-skills 固定版本，见 [出处与许可证](sources.md)；不是官方指南。运行与付费仅走 Wowidea，忽略其他服务调用方式。
先确定一个镜头意图，再按“主体 + 动作 + 场景 + 镜头 + 光线/风格 + 声音 + 保持约束”组织。主体和主动作前置，删除空泛质量词。
文本模式建立完整画面；图像模式只补动态、时间、镜头和保持项。视频参考明确迁移的是运动、节奏还是镜头，不顺带迁移身份。
首尾帧把第二帧写为明确视觉终点，描述连续过渡。编辑只改变指定层；续写必须读取已接受视频真实尾帧，不能把计划结尾当作实际结尾。
每个参考独立指定角色；多镜头写时段与切点，事件总量不得超过实际时长。用可见动作替代抽象情绪，保留连续性和产品/人物锁定。
2.0 与 fast 的限制分别看平台目录。所有版本仍需 [Seedance 门禁](seedance-gate.md)。
